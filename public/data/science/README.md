The product target for this task was 80 records per age group, 800 total. This
starter bank prioritizes manually reviewed, source-verified records over
procedural expansion or superficial variants.

Record standards:

- Each object uses category `science` and reviewStatus `reviewed`.
- Each object has exactly four unique answer choices.
- `correctAnswer` must match one of the choices exactly.
- Question and explanation wording is original and fact-checked against the
  listed source.
- Sources are restricted to reliable government, museum, standards, or
  education pages such as NASA, NOAA, USGS, NIST, Smithsonian, and NHGRI.
- No pop culture, sports-fandom, celebrity, trend, horse, or equestrian content.
