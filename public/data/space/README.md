Record standards:

- Each object uses category `space` and reviewStatus `reviewed`.
- Each age group from 9 through 18+ has exactly 70 records.
- Each object has exactly four unique answer choices.
- `correctAnswer` matches one of the choices exactly.
- Question wording is factual, non-pop-culture, and age-appropriate.
- Sources are reliable astronomy or space-weather sources, primarily NASA Science, NASA Solar System Exploration, ESA, and NOAA SWPC.
- Orbital weightlessness is described as continuous free fall with gravity still acting; no record says gravity turns off or mass becomes zero.
- No horse or equestrian content is included.
