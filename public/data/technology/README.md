# Technology Question Bank

Static, reviewed technology questions for Quizzer. The bank currently contains 500 multiple-choice records: 50 for each age group from 9 through 18+.

Each record uses the required fields: `id`, `ageGroup`, `category`, `difficulty`, `question`, four unique `choices`, `correctAnswer`, `explanation`, `sourceName`, `sourceUrl`, and `reviewStatus: "reviewed"`.

Question wording and explanations are original. Sources are used for fact verification and topic grounding. The file intentionally avoids pop-culture prompts and horse/equestrian content.
